Splunk Home Lab: Installing Splunk Enterprise and Loading the BOTS v3 Dataset

Timothy Dada · August 2026

Objective

Build a working home SOC lab by installing Splunk Enterprise locally and loading a realistic practice dataset, so I have an actual environment to learn log analysis and alert investigation on — rather than just studying the concepts.

Tools Used

  • Splunk Enterprise (free 60-day trial), Windows
  • Splunk BOTS v3 dataset — Splunk's official public practice dataset of simulated security incident data
  • 7-Zip, for extracting the dataset archive
  • PowerShell (elevated/admin), for moving files into a protected system directory and restarting the Splunk service

What I Did

  • Installed Splunk Enterprise's free trial on Windows and confirmed access to the web UI at localhost:8000.
  • Downloaded the official BOTS v3 dataset (~320MB) directly from Splunk's public repository.
  • Extracted the archive with 7-Zip and located the actual Splunk install directory using the Windows Task Manager process list, since direct folder navigation was initially blocked.
  • Copied the extracted dataset into Splunk's etc\apps directory using an elevated PowerShell session, since Program Files requires admin rights to write to.
  • Restarted the Splunk service and confirmed the new data source loaded successfully.
  • Ran a verification search to confirm the dataset was indexed and queryable.

Issues Hit & How I Fixed Them

Extracting the archive initially produced an unrelated "Lang" folder full of translation files — turned out to be a mix-up with a separate download (7-Zip's own installer files), not the actual dataset.
Fix: re-verified the correct source file (botsv3_data_set.tgz, confirmed by hash/size) and re-extracted it directly.
Could not navigate to C:\Program Files\Splunk directly in File Explorer or Command Prompt.
Fix: located the real install path via Task Manager's process list (found splunkd.exe), then confirmed the exact path.
Copying the dataset folder into etc\apps failed silently — Program Files is a protected system directory.
Fix: ran the copy and the Splunk restart command from an elevated (Administrator) PowerShell session.

Official Practice Questions

Splunk provided the official BOTS v3 question set (58 questions with point values and hints) after a direct request. Built a personal tracking workbook to work through them against the loaded dataset: a dashboard for progress, a question-by-question worksheet with status tracking, and a separate answer key to self-check without spoiling attempts before trying.
