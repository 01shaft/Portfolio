API/SDK Security Assessment: Mobile SDK Review

Timothy Dada · York University Cybersecurity Operations Capstone · 2026

This engagement is protected under a signed NDA with the client. Client name, credentials, endpoints, and reproduction specifics are intentionally omitted from this public writeup. Full technical detail is available for discussion in an interview or on request.

Objective

Evaluate the security of a fintech client's mobile SDK integration (Android) as part of a scoped, authorized security review — covering credential handling, sign-in logic, root/tamper detection, and transport security.

Tools Used

  • Rooted Android emulator (Google APIs system image) — required for genuine root-detection testing
  • adb (Android Platform Tools) — device interaction and APK extraction
  • jadx — decompiling the APK to review the SDK's actual source
  • Burp Suite — intercepting and inspecting live network traffic
  • Chrome DevTools — inspecting web-based components of the platform
  • An internal automated testing framework, for a companion feature-testing workstream

What I Did

  • Set up a rooted Android emulator and pulled the target application's APK directly from a running device via adb.
  • Decompiled the APK with jadx to review the SDK's actual source and cross-reference it against live application behavior.
  • Registered a real device against the client's onboarding environment and exercised the app's core flows, capturing logs, network traffic, and screenshots as evidence for every finding.
  • Ran structured reconnaissance against the client's public-facing endpoints following an authorized, phased testing methodology, focused on authorization boundaries and business logic.
  • Ran a companion feature-testing workstream: automated and manual coverage across policy management, API gateway configuration, and core tunnel-establishment functionality.
  • Documented every finding with reproduction steps, supporting evidence, and a remediation recommendation, delivered in a formal report to the client.
